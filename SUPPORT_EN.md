# Support

[Русский](SUPPORT.md) · [English](SUPPORT_EN.md)

## Installation question

Run the diagnostics in [docs/SETUP_EN.md](docs/SETUP_EN.md) and search existing issues first. If no answer exists, open an issue using the bug-report template.

Include OS and Docker versions, the commit, exact steps, expected behavior, and a safe log excerpt. Remove tokens, passwords, customer emails, and private filenames.

## Idea or feature

Use the feature-request template. Describe the workshop problem, not only the proposed button.

## Vulnerability

Follow [SECURITY_EN.md](SECURITY_EN.md) and do not disclose it publicly.
