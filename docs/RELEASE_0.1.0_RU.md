# PrintForge v0.1.0

Первый полноценный релиз Workshop OS для небольшой мастерской и фермы 3D-печати.

## Главное

- публичная форма `/request`: клиент загружает модель и сразу получает код;
- история заказа, фотографии производства, стоимость, PDF и скачивание файлов;
- Telegram-подписка и автоматические уведомления о статусе;
- импорт STL, OBJ, 3MF, G-code/GCO; чтение оценки времени и пластика;
- производственный календарь;
- local или S3-совместимое хранилище, включая Cloudflare R2;
- устанавливаемое PWA с офлайн-экраном;
- полный backup PostgreSQL + uploads;
- HTTPS-профиль Docker Compose с Caddy;
- Go unit-тесты, API smoke E2E и Playwright desktop/mobile.

## Обновление

```bash
./scripts/backup.sh
git pull --ff-only
docker compose up --build -d
node tests/e2e/smoke.mjs
```

Миграция `004_workshop_release.sql` запускается автоматически и сохраняет существующие данные.

## Проверка после обновления

1. Откройте `/request`, отправьте тестовый STL и сохраните код.
2. В «Заказы» найдите «Заявку с сайта».
3. Добавьте этап и фотографию через «Фото и история».
4. Проверьте историю, фото, модель и PDF на публичной странице.
5. Создайте задание с запланированным стартом и проверьте «Календарь».
6. Отправьте код Telegram-боту, измените статус и дождитесь уведомления.

## Ограничения

- PDF — расчётная квитанция, а не фискальный кассовый чек.
- Оценку слайсера нужно подтвердить перед фактическим списанием.
- Для публичного HTTPS-развёртывания нужен собственный VPS и домен.
