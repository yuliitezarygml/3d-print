# Как внести вклад в PrintForge

[Русский](CONTRIBUTING.md) · [English](CONTRIBUTING_EN.md)

Спасибо за интерес к проекту. Мы приветствуем исправления, документацию, новые профили принтеров, тесты и улучшения пользовательских сценариев.

## До начала работы

1. Проверьте существующие issues.
2. Для крупной функции сначала создайте feature request и опишите пользовательский сценарий.
3. Не публикуйте реальные данные клиентов, токены Telegram, `.env`, дампы базы и приватные 3D-модели.

## Локальный запуск

```bash
git clone https://github.com/yuliitezarygml/3d-print.git
cd 3d-print
cp .env.example .env
docker compose up --build -d
```

Подробности: [docs/SETUP_RU.md](docs/SETUP_RU.md).

## Ветки и коммиты

- создавайте ветку от актуальной `main`;
- используйте короткое имя: `fix/receipt-total`, `feat/printer-filter`;
- один коммит должен описывать одну логическую правку;
- сообщение пишите в повелительном наклонении, например `Fix receipt totals`.

## Обязательные проверки

```bash
(cd apps/backend && gofmt -w . && go test ./...)
(cd apps/frontend && npm ci && npm run lint && npm run build)
docker compose config
node tests/e2e/smoke.mjs
```

E2E требует запущенный стек на `http://localhost`.

## Pull request

В PR укажите проблему, способ проверки, изменённые API/миграции, скриншоты для интерфейса и результаты тестов.

Новый код должен сохранять денежные значения в точных decimal/NUMERIC типах, проверять авторизацию, не раскрывать чужие заказы и сопровождаться тестом на основной сценарий.

## Лицензия

Отправляя вклад, вы соглашаетесь распространять его по AGPL-3.0 вместе с проектом.
